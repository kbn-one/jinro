---
title: Lasm をやめて自作の WasmGC バックエンドへ
date: "2026-11-24"
summary: Lean のコンパイラが出す中間表現から WasmGC を直接出力するようにしました。wasm は約 115 KB（brotli で約 32 KB）になりました。
---

Lasm は Lean の C ランタイムごと wasm にするため、約 820 KiB
になっていました。そこで Lean のコンパイラが C 出力の手前で作る中間表現
（IR）を読み、WasmGC のモジュールを直接書き出すバックエンドを Lean
で書きました。メモリ管理は wasm 側の GC
に任せるので、参照カウントもランタイムも不要です。ルールと JSON
の取り決めのコードはそのままコンパイルでき、40
ゲームの回帰テストはすべて一致し、 Lasm 版との比較でも応答の文字列が 534
件すべて同じでした。wasm は約 115 KB（brotli 圧縮で約 32 KB）、速度は約 2
倍です。
