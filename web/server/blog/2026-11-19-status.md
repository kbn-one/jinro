人狼エンジン jinro のコアを MoonBit から Rust に移しました。Rust のコードは
Charon と Aeneas で Lean に自動変換し、CI
で毎回証明を検査しています。今月は「死者は行動も投票もできない」をループの帰納法で証明し、仕様とずれていたハムスターの噛み耐性も直しました。wasm
コンポーネントは jco で JS に変換し、このサイトの wasm
ページからブラウザだけで村を作って 1 日ずつ進められます。

## 追記（2026-11-20）

その後、エンジンを WASI のコマンドにして、標準入力に JSON を渡し標準出力の JSON
を受け取る形に変えました。これで jco は不要になりました。さらに同じ JSON
の取り決めのまま、エンジンを Lean で直接書き直し、Lasm で wasm
にしました。乱数で作った 40 ゲームで Rust
版と応答が完全に一致することを確かめてから、Rust 実装は削除しています。Lean
版では、証明を実際に動くコードそのものについて書けます。wasm は約 820
KiB（brotli 圧縮で約 158 KB）で、定理を増やしてもサイズは変わりません。
