---
title: Rust をやめて Lean + Lasm へ
date: "2026-11-20"
summary: エンジンを Lean で直接書き、Lasm で wasm にしました。Rust 実装は削除しました。
---

エンジンを WASI のコマンドにして、標準入力に JSON を渡し標準出力の JSON
を受け取る形に変えました。これで jco は不要になりました。さらに同じ JSON
の取り決めのまま、エンジンを Lean で直接書き直し、Lasm で wasm
にしました。乱数で作った 40 ゲームで Rust
版と応答が完全に一致することを確かめてから、Rust 実装は削除しています。Lean
版では、証明を実際に動くコードそのものについて書けます。wasm は約 820
KiB（brotli 圧縮で約 158 KB）で、定理を増やしてもサイズは変わりません。
